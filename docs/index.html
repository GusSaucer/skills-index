Superpoderes para o seu Claude Code.

Skills, plugins e agentes escolhidos a dedo depois de uma varredura nos marketplaces oficiais e na comunidade. Cada um com o comando para instalar e o momento certo de usar.

    # três trilhas, um comando cada
› /plugin install learning-output-style@claude-plugins-official
  ✓ o Claude agora pede para você escrever o trecho que ensina

› /plugin install superpowers@claude-plugins-official
  ✓ brainstorm → plano → TDD → revisão

› /plugin install marketing-skills@marketingskills
  ✓ copy, SEO e GEO para o seu site

›

    Escolha a sua trilha

    Três caminhos, do primeiro projeto ao sistema em produção. Os marcados com ★ são os que mais impressionam na primeira vez.

    Como instalar, em 30 segundos

    1. Plugin de marketplace: dentro do Claude Code, /plugin marketplace add dono/repo uma vez, depois /plugin install nome@marketplace. O marketplace oficial já vem cadastrado.
    2. Skill solta: no terminal, npx skills add dono/repo, ou copie a pasta para ~/.claude/skills/.
    3. Conferir: /plugin lista o que está instalado; reinicie a sessão se a skill não aparecer.

    Antes de instalar

    • Skill da comunidade pode rodar código na sua máquina. Leia o SKILL.md e os scripts antes.
    • Instale só o que vai usar. Plugin com servidor MCP ocupa contexto em toda sessão.
    • Nomes mudam entre versões: confira no repositório da fonte.

    O catálogo completo

    Tudo o que um setup real tem ligado, mais a curadoria, em skills e agentes. Busque pelo que você quer fazer.

Skills e Agentes — Claude Code

Uma skill é um pacote de instruções que o Claude carrega na própria conversa. Um agente é um Claude separado, com contexto, ferramentas e modelo próprios, que recebe uma tarefa e devolve só o resultado. Este é o catálogo dos dois, tirado de um setup real.
